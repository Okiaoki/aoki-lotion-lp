# 青木化粧水 LP（制作サンプル）

架空の化粧水ブランド「青木化粧水」の販促用ランディングページ（縦長1カラム型・単品リピート通販の王道フォーマット）。ポートフォリオ掲載用の制作サンプルです。

## 特徴

- **スマホ主体設計＋PC対応**：本文は 750px 中央カラムに固定し、ワイドPCでは左右に縦組みの装飾テキストを添えるレイアウト。
- **最新フロントエンド構成**：ビルド工程なしの素の HTML / CSS / JavaScript。文字・バッジ・価格・比較表・CTA はすべてマークアップと CSS/SVG で描画（画像内に文字を焼き込まない設計）。
- **販促装置**：ファーストビューの3冠バッジ・初回50%OFFバースト、各所の脈動CTA、本日23:59へ向けた JS カウントダウン、楽天／Amazon／Yahoo! の各モール誘導ボタン、追従CTA、吹き出し型のお客様の声。
- **画像**：AI生成のビジュアルを WebP 最適化して使用（初回表示のみ eager、以降は遅延読み込み）。
- **iOS(WebKit) セーフ**：禁則効果を避け、Playwright WebKit で SP/タブ/PC の横あふれ0・画像欠け0を確認済み。
- フォームは疑似送信（実送信なし）。各種CTAはデモ用の外部ECダミーURLへ遷移。

## 構成

```
index.html        本体（全セクション）
css/style.css     スタイル一式（デザイントークン→各セクション）
js/main.js        カウントダウン／出現アニメ／CTA導線／モーダル／フォーム
img/              WebP画像・favicon・OGP
```
